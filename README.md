# LogicMin

**Simplifying Boolean logic, visualizing circuits.**

LogicMin is a web-based digital logic tool designed to help students explore Boolean function minimization and understand how simplified expressions translate into logic circuits.

## Features

- **Boolean Logic Minimization** — Simplify Boolean functions.
- **Karnaugh Maps** — Visualize Boolean simplification using K-maps.
- **Logic Circuit Visualization** — Explore circuit representations of Boolean expressions.
- **Verilog Generation** — Generate Verilog code for supported logic functions.
- **Interactive Interface** — Work with digital logic through a visual interface.

## Built With

- React
- Vite
- JavaScript
- Lucide React

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd logic-min
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Build

To create a production build, run:

```bash
npm run build
```
